# dB-Linear-Programmable-Gain-Amplifier-PGA-Cadence-Virtuoso
Cascaded unit-cell PGA in 45nm CMOS with 76 dB linear gain range using 5-bit digital/analog control. Verified via pre-layout (AC/transient) with stable 552 mV bias and consistent gain (1 vs 3 stages). Implemented DCOC and optimized headroom for high-bandwidth signal integrity.
